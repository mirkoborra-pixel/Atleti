# Roster Atleti - semplice

Istruzioni rapide:

Installare dipendenze e avviare il dev server:

```bash
npm install
npm run dev
```

Aprire l'URL mostrato dal server (di solito http://localhost:5173).

Descrizione: progetto semplice che permette di aggiungere atleti con nome, disciplina e foto (URL), segnare chi è in squadra, filtrare e eliminare. I dati vengono salvati in localStorage.
